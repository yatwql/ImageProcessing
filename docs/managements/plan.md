## 4. 约束提醒

- 写盘日志属于核心能力，实现只能在 `core/audit.py`，渠道不得自己拼 JSON。
- 任何新增写图片的路径（新格式、导出、缩略图）都必须调用同一个 `record_write`。
- 用例不得写仓库 `logs/`、`data/`，一律用临时目录 + `IMG_P_LOG_DIR`。
